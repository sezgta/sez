# SEZ — Liquid Desktop

一个没有跳转链接的液态玻璃体验站。点击任意「唤醒 SEZ」，进入一套可以真正操作的液态玻璃手机桌面。

## 本地预览

```powershell
cd "D:\鱼的工作区\liquid-glass-site"
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。纯静态 HTML / CSS / JavaScript，无构建步骤、无第三方依赖、无外部资源请求。

## SEZ 液态桌面

唤醒后会打开一块全屏液态玻璃手机桌面，包含：

- **实时首页**：本地时间、昼夜问候、天气组件、四枚玻璃应用图标、玻璃 Dock。
- **天气**：上海天气详情、逐时温度、四日预报。
- **笔记**：可在手机里直接输入，自动保存到浏览器本地存储。
- **照片**：六张 SEZ 光研究，可打开全屏查看。
- **设置**：三套壁纸、三种光色、实时高光与流动动效开关。
- **控制中心**：Wi-Fi、高光、流动、搜索、亮度、音量、壁纸与休眠。
- **专注**：25 / 45 / 5 分钟计时、开始 / 暂停 / 重置与进度环。
- **音乐**：三首可切换的生成式环境音，真实使用 Web Audio 实时合成。
- **搜索**：支持中英文应用搜索，回车直接打开第一项。

## 交互细节

- 点击「唤醒 SEZ」后，整页光效 + 玻璃桌面平滑展开。
- 应用从图标位置缩放打开；关闭时按相反方向收回。
- 首页会随应用打开退后、模糊，形成真实层级。
- 从手机底部横条上滑可返回桌面；点击也可以。
- Esc：先退出应用，再退出桌面；支持完整焦点陷阱与键盘操作。
- 支持 320px–1440px；`prefers-reduced-motion` 下自动降级。

## 技术

- 原生 CSS 变量、`backdrop-filter`、SVG `feTurbulence + feDisplacementMap` 位移折射。
- Web Animations API 负责应用打开 / 关闭的共享元素缩放动画。
- Web Audio API 生成低音量环境音，首次点击播放时创建音频上下文。
- 全部资源本地化，页面中没有任何 `<a>` 标签或外部跳转。
